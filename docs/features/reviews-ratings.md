# المراجعات والتقييمات

توثيق التنفيذ داخل مشروع الواجهة: [frontend/docs/features/reviews-ratings.md](../../frontend/docs/features/reviews-ratings.md).

## الحالة الحالية

يمكن لأي زائر قراءة المراجعات. يستطيع المستخدم المسجل إضافة مراجعة نصية وتقييم من 1 إلى 5 نجوم، ثم تعديل مراجعته أو حذفها. يسمح قيد قاعدة البيانات بمراجعة واحدة فقط من كل مستخدم لكل كتاب. في صفحة التفاصيل، تتحول عملية الحفظ إلى تحديث إذا كانت للمستخدم مراجعة سابقة.

شكل النجوم والبطاقات ونموذج الكتابة أصبح أبيض وأسود؛ نص المراجعات وتسميات النموذج تتبع [مقياس الخط المركزي](visual-identity.md) مع تباعد أسطر نسبي. بقيت قواعد الحفظ والتعديل والحذف كما هي.

## مسار العمل والارتباطات

في الفرونت، لا توجد صفحة مراجعات مستقلة أو مكون `ReviewForm` منفصل؛ نموذج النجوم والنص وحالتهما داخل صفحة تفاصيل الكتاب. وظائف REST في `lib/api.ts` والزر المشترك في `components/ui/button.tsx`. راجع [خريطة الفرونت إند](frontend-map.md).

نموذج النجوم والنص في `frontend/app/books/[id]/page.tsx` → `books.review` أو `books.deleteReview` في `frontend/lib/api.ts` → مسارات محمية في `backend/internal/routes/routes.go` → `SaveReview` و`DeleteReview` في `backend/internal/handlers/api.go` → جدول `reviews` في SQLite.

يتحقق Go من وجود الكتاب، وأن التقييم بين 1 و5، وأن نص المراجعة بعد إزالة الفراغات لا يقل عن 3 بايتات. `PUT` يستخدم `INSERT ... ON CONFLICT` للإنشاء أو التعديل، ويحدّث `created_at` عند التعديل. الحذف مقيد بـ`book_id` و`user_id` كي لا يحذف المستخدم مراجعة غيره. بعد الحفظ/الحذف تعيد الصفحة تحميل بيانات الكتاب والمراجعات. تُحسب `average_rating` و`review_count` عند قراءة الكتب، ولذلك تتأثر [القائمة](catalog-search.md) و[التفاصيل](book-details.md).

## API والبيانات

| الطريقة والمسار | الوظيفة |
|---|---|
| `GET /api/books/{id}` | يعيد المراجعات ضمن تفاصيل الكتاب؛ عام |
| `PUT /api/books/{id}/review` | جسم `{rating,body}`؛ ينشئ/يعدل مراجعة المستخدم؛ يتطلب دخولًا |
| `DELETE /api/books/{id}/review` | يحذف مراجعة المستخدم؛ يتطلب دخولًا |

جدول `reviews`: `id`, `book_id`, `user_id`, `rating`, `body`, `created_at`، مع `UNIQUE(book_id,user_id)` و`CHECK(rating BETWEEN 1 AND 5)` ومفاتيح أجنبية. توجد مراجعتان أوليتان للعرض عند تهيئة قاعدة فارغة، ويظهر كاتبهما باسم «قارئ من منصة قارئ».

## غير موجود أو غير مكتمل

- لا توجد إعجابات بالمراجعات أو إبلاغ عنها أو ردود عليها.
- لا يوجد ترقيم صفحات للمراجعات، واسم `created_at` يُستخدم أيضًا كتاريخ آخر تعديل.
- حد طول النص في Go محسوب بالبايتات، ولا يوجد حد أقصى واضح لطول المراجعة.
