إذا بدت ملفات الميزة وكأنها صفحات فقط، ابدأ من [خريطة الفرونت إند](frontend-map.md): تشرح أن `app/` للمسارات، و`components/` للواجهة المشتركة، و`lib/api.ts` لخدمات الاتصال.

توجد الآن ملفات مخصصة للواجهة **داخل مشروع الفرونت نفسه** في [frontend/docs/features](../../frontend/docs/features/README.md). عند تعديل الفرونت، حدّث الملف المحلي والملف الشامل المناظر هنا معًا.

**طريقة التحديث:** عدّل وصف السلوك والملفات والارتباطات عندما تتغير، ثم أضف سطرًا مؤرخًا في «سجل التغييرات» يوضح ما تغير وكيف تحققته. اكتب أي قيد معروف في «غير موجود أو غير مكتمل». لا تكتفِ بإضافة سطر في السجل إذا أصبح الشرح القديم غير صحيح.
