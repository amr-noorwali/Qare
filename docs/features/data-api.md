# قاعدة البيانات وREST API والإعدادات

## الحالة الحالية

المشروعان مستقلان: Next.js في `frontend/` وGo في `backend/`. الواجهة تتواصل مع Go عبر HTTP/JSON فقط. يستخدم Go `net/http` و`modernc.org/sqlite`، ويفتح افتراضيًا `backend/qare.db` عند التشغيل من مجلد `backend`. ينشئ الجداول والفهارس عند بدء التشغيل إذا لم تكن موجودة، ويضيف ستة كتب ومراجعتين إلى قاعدة فارغة. اسم حساب المراجعات التجريبي هو «قارئ من منصة قارئ»؛ يحدّث Go هذا الاسم للحساب التجريبي عند فتح قاعدة قديمة. الحساب غير مخصص للدخول.

## مسار الطلب

لخريطة أدق للفرونت من الصفحة إلى المكون وخدمة REST، راجع [خريطة الفرونت إند](frontend-map.md). هذه الطبقة لا تملك صفحات مستقلة؛ يستخدمها كل مسار عبر `lib/api.ts`.

`frontend/app` → `frontend/lib/api.ts` → `http://localhost:8080/api` → `backend/internal/routes/routes.go` → `backend/internal/handlers/api.go` → `backend/internal/services/auth.go` أو `backend/internal/repositories/*.go` → SQLite.

**ملاحظة عن الفصل:** خدمة المصادقة موجودة في `services/auth.go`، واستعلامات القراءة في `repositories/books.go`، لكن بعض عمليات كتابة المراجعات والمكتبة تنفذ SQL داخل `handlers/api.go`. هذا واقع الـMVP الحالي، وليس فصلًا كاملًا لكل منطق العمل.

## الجداول والعلاقات

| الجدول | الدور والعلاقة |
|---|---|
| `users` | بيانات المستخدم والبريد الفريد وتجزئة كلمة المرور |
| `sessions` | رمز الجلسة، المستخدم المرتبط، وتاريخ الانتهاء |
| `books` | بيانات الكتب والغلاف والنوع |
| `reviews` | مراجعة المستخدم للكتاب؛ تقييم 1–5 ومراجعة واحدة لكل زوج مستخدم/كتاب |
| `library` | تصنيف كتاب واحد لكل مستخدم؛ `want`, `reading`, `read` |

مفاتيح العلاقات الأجنبية مفعلة، والفهارس الإضافية موجودة للمراجعات حسب الكتاب والتاريخ، والمكتبة حسب الكتاب، والجلسات حسب المستخدم. متوسط التقييم وعدد المراجعات يُحسبان في استعلامات القراءة ولا يُخزنان في `books`.

## نقاط REST الـ11

| المجال | النقاط |
|---|---|
| المصادقة | `POST /auth/register`, `POST /auth/login`, `GET /auth/me`, `POST /auth/logout` |
| الكتب | `GET /books`, `GET /books/{id}` |
| المراجعات | `PUT /books/{id}/review`, `DELETE /books/{id}/review` |
| المكتبة | `GET /library`, `PUT /library/{id}`, `DELETE /library/{id}` |

أضف `/api` قبل كل مسار في الجدول. تفاصيل الأجسام والأكواد في `backend/README.md`، واستخدام الواجهة في `frontend/lib/api.ts`. المسارات المحمية تستخدم Bearer token. الأخطاء المعتادة تعيد `{ "error": "..." }`.

## الإعدادات والتشغيل

- `backend/.env.example`: `PORT=8080`, `DATABASE_PATH=./qare.db`, `FRONTEND_ORIGIN=http://localhost:3000`. يقرأ Go **متغيرات البيئة الفعلية** ولا يحمّل ملف `.env` تلقائيًا.
- `frontend/.env.example`: `NEXT_PUBLIC_API_URL=http://localhost:8080/api`، وهذا هو الافتراضي أيضًا.
- شغّل `go run .` من `backend/`، و`npm run dev` من `frontend/`. تحقق من Go بـ`go test ./...` ومن الواجهة بـ`npm run lint` و`npm run build`.
- ملف قاعدة البيانات المحلي مُستثنى من Git؛ يمكن إنشاؤه تلقائيًا عند تشغيل Go على جهاز جديد.

## غير موجود أو غير مكتمل

- لا توجد هجرات SQL مرقمة، ولا نسخ احتياطي تلقائي، ولا إعداد نشر إنتاجي.
- لا يوجد ترقيم صفحات في API، ولا حد معدل للطلبات. قاعدة SQLite المحلية مناسبة لحجم الـMVP المحلي.
