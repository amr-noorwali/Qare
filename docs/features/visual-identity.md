# الهوية البصرية والواجهة العربية

توثيق التنفيذ داخل مشروع الواجهة: [frontend/docs/features/visual-identity.md](../../frontend/docs/features/visual-identity.md).

## الحالة الحالية

الواجهة عربية واتجاهها `rtl` من `frontend/app/layout.tsx`، ومتجاوبة مع الجوال عبر Tailwind CSS. اسم المنصة الظاهر هو **قارئ**. الخط المعتمد هو **Tajawal** بأوزان 400 و500 و700 و800 من حزمة `@fontsource/tajawal` المحلية. الشعار المقدم من المستخدم محفوظ في `frontend/public/qare-logo.svg`، ويظهر في الترويسة ونموذج الدخول/التسجيل. أيقونة التبويب `frontend/app/icon.svg` تحمل الرمز نفسه باللون الأبيض على مربع أسود لظهوره على خلفيات التبويب الفاتحة والداكنة.

الهوية الحالية أحادية اللون: أبيض وأسود ورماديات فقط. الهيرو يعرض صورة كومة الكتب الشفافة التي قدمها المستخدم بحجم أصغر فوق أرضية الصفحة البيضاء، ونصًا أسود بلا تدرجات أو زجاج. قسم «حكاية قارئ» يعرض صورة اليدين والكتاب الشفافة التي قدمها المستخدم دون خلفية منفصلة، مع بطاقة شرح سوداء شبه معتمة بعتامة 92% وزوايا مستديرة 12px ومن دون ظل. تبقى الصورة التحريرية `editorial-library.webp` خلفية لنماذج الحساب، والألواح الزجاجية الشفافة (`glass-light` و`glass-dark`) في الأقسام. تبقى Tajawal خط المنصة.

## مقياس الخط

تُعرّف أحجام النص مركزيًا في `frontend/tailwind.config.ts` بوحدات `rem` نسبةً إلى حجم المتصفح الافتراضي. النص الأساسي 17px، ونصوص التحكم والتنقل 16px، والتسميات المساعدة 14px، ونص المقدمة 19–22px، وعناوين الأقسام 36px على الجوال و54px على الشاشات الواسعة. عنوان الهيرو 44px ثم 54px؛ النصوص الطويلة بتباعد أسطر نسبي نحو 1.6–1.7. أزيل تباعد الحروف الواسع من التسميات العربية في `section-kicker`، وخُفّض الفراغ المفرط بين أسطر الفقرات.

هذه اختيارات تصميمية مبنية على [إرشادات USWDS لأحجام النصوص وتباعد الأسطر](https://designsystem.digital.gov/components/typography/) و[مقياس أحجامه](https://designsystem.digital.gov/design-tokens/typesetting/font-size/)، مع مراعاة [إرشاد W3C لتكبير النص إلى 200% دون فقد المحتوى](https://www.w3.org/WAI/WCAG21/Understanding/resize-text). الأرقام اختيار لهذا المشروع وخط Tajawal، وليست حدودًا إلزامية عامة لكل المواقع العربية.

## الارتباطات

ملفات الهوية في الفرونت موزعة بين `layout.tsx` و`globals.css` و`tailwind.config.ts` والمكونات المشتركة والأصول؛ ليست صفحة مستقلة. انظر [خريطة الفرونت إند](frontend-map.md).

| العنصر | الموضع |
|---|---|
| اتجاه اللغة والخط على جسم الصفحة | `frontend/app/layout.tsx` |
| ألوان `ink`, `paper`, `mist`, `line`, `muted`، خط `font-sans`، ومقياس أحجام الخط المركزي | `frontend/tailwind.config.ts` |
| استيراد Tajawal وتأثيرات الزجاج والصور والانتقال | `frontend/app/globals.css` |
| الشعار والتنقل المتجاوب | `frontend/components/header.tsx` |
| أيقونة تبويب بيضاء على خلفية سوداء | `frontend/app/icon.svg` |
| شعار نماذج الدخول والتسجيل | `frontend/components/auth-form.tsx` |
| زر مشترك بأسلوب shadcn/ui و`class-variance-authority` | `frontend/components/ui/button.tsx`, `frontend/components.json` |
| بطاقات الكتب | `frontend/components/book-card.tsx` |
| أقسام الصفحة الرئيسية التحريرية | `frontend/components/landing/` |
| صورة كومة الكتب المقدمة من المستخدم للهيرو | `frontend/public/hero-book-stack.png` |
| صورة قصة قارئ المقدمة من المستخدم | `frontend/public/story-hands-book.png` |
| صورة خلفية نماذج الحساب | `frontend/public/editorial-library.webp` |

الهوية البصرية تؤثر في جميع [الصفحات والميزات](README.md)، ولا تتصل مباشرة بقاعدة البيانات أو REST API.

## غير موجود أو غير مكتمل

- توجد درجات رمادية ومسافات مكتوبة مباشرة في بعض الصفحات؛ لذلك الثيم مركزي **جزئيًا** وليس نظام تصميم كاملًا.
- لا يوجد وضع داكن أو مكتبة مكونات shadcn/ui واسعة؛ الموجود إعداد shadcn/ui ومكون زر واحد مشترك.
- أبعاد الشعار ومواضعه مخصصة حاليًا للترويسة ونماذج المصادقة وأيقونة المتصفح.
