# الهوية البصرية والواجهة العربية

## الحالة الحالية

الواجهة عربية واتجاهها `rtl` من `frontend/app/layout.tsx`، ومتجاوبة مع الجوال عبر Tailwind CSS. الخط المعتمد هو **Tajawal** بأوزان 400 و500 و700 و800 من حزمة `@fontsource/tajawal` المحلية. الشعار المقدم من المستخدم محفوظ في `frontend/public/qare-logo.svg`، ويظهر في الترويسة ونموذج الدخول/التسجيل، ونسخته `frontend/app/icon.svg` هي أيقونة الموقع.

## الارتباطات

| العنصر | الموضع |
|---|---|
| اتجاه اللغة والخط على جسم الصفحة | `frontend/app/layout.tsx` |
| ألوان `ink`, `moss`, `cream`, `gold` وخط `font-sans` | `frontend/tailwind.config.ts` |
| استيراد ملفات Tajawal وبعض الأنماط العامة | `frontend/app/globals.css` |
| الشعار والتنقل المتجاوب | `frontend/components/header.tsx` |
| شعار نماذج الدخول والتسجيل | `frontend/components/auth-form.tsx` |
| زر مشترك بأسلوب shadcn/ui و`class-variance-authority` | `frontend/components/ui/button.tsx`, `frontend/components.json` |
| بطاقات الكتب | `frontend/components/book-card.tsx` |

الهوية البصرية تؤثر في جميع [الصفحات والميزات](README.md)، ولا تتصل مباشرة بقاعدة البيانات أو REST API.

## غير موجود أو غير مكتمل

- توجد ألوان ومسافات مكتوبة مباشرة في بعض الصفحات، مثل خلفيات الأقسام؛ لذلك الثيم مركزي **جزئيًا** وليس نظام تصميم كاملًا.
- لا يوجد وضع داكن أو مكتبة مكونات shadcn/ui واسعة؛ الموجود إعداد shadcn/ui ومكون زر واحد مشترك.
- أبعاد الشعار ومواضعه مخصصة حاليًا للترويسة ونماذج المصادقة وأيقونة المتصفح.
