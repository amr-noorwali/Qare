# الهوية البصرية والواجهة العربية

توثيق التنفيذ داخل مشروع الواجهة: [frontend/docs/features/visual-identity.md](../../frontend/docs/features/visual-identity.md).

## الحالة الحالية

الواجهة عربية واتجاهها `rtl` من `frontend/app/layout.tsx`، ومتجاوبة مع الجوال عبر Tailwind CSS. اسم المنصة الظاهر هو **قارئ**. الخط المعتمد هو **Tajawal** بأوزان 400 و500 و700 و800 من حزمة `@fontsource/tajawal` المحلية. الشعار المقدم من المستخدم محفوظ في `frontend/public/qare-logo.svg`، ويظهر في الترويسة ونموذج الدخول/التسجيل، ونسخته `frontend/app/icon.svg` هي أيقونة الموقع.

الهوية الحالية أحادية اللون: أبيض وأسود ورماديات فقط. الهيرو يستخدم صورة كومة الكتب المقدمة من المستخدم على خلفية سوداء، ونصًا أسود على أرضية بيضاء بلا تدرجات أو زجاج. تبقى الصور التحريرية الرمادية والألواح الزجاجية الشفافة (`glass-light` و`glass-dark`) في بقية الموقع. صورتا `editorial-library.webp` و`editorial-reading.webp` أُنشئتا للمشروع وضُغطتا إلى WebP؛ الأولى لخلفية نماذج الحساب والثانية لقسم القصة. تبقى Tajawal خط المنصة.

## الارتباطات

ملفات الهوية في الفرونت موزعة بين `layout.tsx` و`globals.css` و`tailwind.config.ts` والمكونات المشتركة والأصول؛ ليست صفحة مستقلة. انظر [خريطة الفرونت إند](frontend-map.md).

| العنصر | الموضع |
|---|---|
| اتجاه اللغة والخط على جسم الصفحة | `frontend/app/layout.tsx` |
| ألوان `ink`, `paper`, `mist`, `line`, `muted` وخط `font-sans`؛ مع أسماء قديمة مرتبطة بدرجات رمادية للتوافق | `frontend/tailwind.config.ts` |
| استيراد Tajawal وتأثيرات الزجاج والصور والانتقال | `frontend/app/globals.css` |
| الشعار والتنقل المتجاوب | `frontend/components/header.tsx` |
| شعار نماذج الدخول والتسجيل | `frontend/components/auth-form.tsx` |
| زر مشترك بأسلوب shadcn/ui و`class-variance-authority` | `frontend/components/ui/button.tsx`, `frontend/components.json` |
| بطاقات الكتب | `frontend/components/book-card.tsx` |
| أقسام الصفحة الرئيسية التحريرية | `frontend/components/landing/` |
| صورة كومة الكتب المقدمة من المستخدم للهيرو | `frontend/public/hero-book-stack.png` |
| الصور التحريرية المحلية | `frontend/public/editorial-library.webp`, `frontend/public/editorial-reading.webp` |

الهوية البصرية تؤثر في جميع [الصفحات والميزات](README.md)، ولا تتصل مباشرة بقاعدة البيانات أو REST API.

## غير موجود أو غير مكتمل

- توجد درجات رمادية ومسافات مكتوبة مباشرة في بعض الصفحات؛ لذلك الثيم مركزي **جزئيًا** وليس نظام تصميم كاملًا.
- لا يوجد وضع داكن أو مكتبة مكونات shadcn/ui واسعة؛ الموجود إعداد shadcn/ui ومكون زر واحد مشترك.
- أبعاد الشعار ومواضعه مخصصة حاليًا للترويسة ونماذج المصادقة وأيقونة المتصفح.
