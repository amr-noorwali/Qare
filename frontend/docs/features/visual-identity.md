# الهوية البصرية في الواجهة

## الحالة الحالية

الواجهة عربية `rtl` ومتجاوبة. الخط الافتراضي Tajawal بأوزان 400 و500 و700 و800 من حزمة `@fontsource/tajawal`. تظهر نسخة SVG من الشعار في الترويسة ونموذج الدخول/التسجيل، ونسخة منه كأيقونة للمتصفح.

## الملفات والارتباطات

| الملف | الدور |
|---|---|
| `app/layout.tsx` | لغة `ar`، اتجاه `rtl`، الترويسة والتذييل |
| `app/globals.css` | تحميل ملفات Tajawal والأنماط العامة |
| `tailwind.config.ts` | ألوان `ink`, `moss`, `cream`, `gold` وربط `font-sans` بخط Tajawal |
| `components/header.tsx` | عرض الشعار والتنقل المتجاوب |
| `components/auth-form.tsx` | الشعار في نماذج المصادقة |
| `components/ui/button.tsx`, `lib/utils.ts`, `components.json` | زر UI المشترك وإعداد shadcn/ui |
| `public/qare-logo.svg`, `app/icon.svg` | أصول الشعار |

هذه ميزة مشتركة تؤثر في الصفحات كلها ولا تستدعي REST API. مزيد من التفاصيل في [الملف الشامل](../../../docs/features/visual-identity.md).

## غير مكتمل

الثيم مركزي جزئيًا؛ بعض الألوان والمسافات مكتوبة مباشرة في الصفحات. لا يوجد وضع داكن أو مكتبة مكونات كاملة.
