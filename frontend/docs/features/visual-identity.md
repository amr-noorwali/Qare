# الهوية البصرية في الواجهة

## الحالة الحالية

الواجهة عربية `rtl` ومتجاوبة. الخط الافتراضي Tajawal بأوزان 400 و500 و700 و800 من حزمة `@fontsource/tajawal`. تظهر نسخة SVG الداكنة من الشعار في الترويسة ونموذج الدخول/التسجيل. أيقونة التبويب `app/icon.svg` تعرض الرمز بالأبيض على خلفية سوداء.

اسم المنصة الظاهر للمستخدم هو «قارئ» في الترويسة والتذييل ونموذج الدخول والعناوين. الثيم الحالي أبيض وأسود مع درجات رمادية ولوحات زجاجية شفافة. الهيرو يعرض صورة كومة الكتب الشفافة التي قدمها المستخدم (`hero-book-stack.png`) فوق الخلفية البيضاء من دون حاوية سوداء، بعرض 80% وبحد أقصى 470px. نص الهيرو وصورته يظهران بحركة CSS قصيرة عند فتح الصفحة، وتُعطّل عند تفضيل تقليل الحركة. قسم قصة قارئ يعرض صورة اليدين والكتاب الشفافة (`story-hands-book.png`) كاملة دون خلفية منفصلة، مع بطاقة شرح سوداء شبه معتمة بعتامة 92% وزوايا مستديرة 12px ومن دون ظل. الصورة التحريرية للمكتبة بقيت خلفية لنماذج الحساب.

مقياس الخط المركزي في `tailwind.config.ts`: `text-xs` ‏14px للتسميات، `text-sm` ‏16px للتحكم والتنقل، `text-base` ‏17px للنص، `text-lg` ‏19px للمقدمات، ثم درجات للعناوين حتى `text-7xl` ‏64px. عنوان الهيرو والمكتبة يستخدمان الدرجات نفسها بمقاسات متجاوبة. يحدد `app/globals.css` حجم الجسم 17px وتباعد أسطره النسبي 1.7، وتستخدم الفقرات الطويلة `leading-relaxed`. لا يستخدم النص العربي في `section-kicker` تباعد حروف زخرفيًا. أصناف الحركة المشتركة `page-enter` و`scroll-reveal` و`interactive-lift` تستخدم `opacity` و`transform` فقط؛ تبقى العناصر مرئية دائمًا، وتُعطّل الحركات عند تفضيل تقليل الحركة.

## الملفات والارتباطات

| الملف | الدور |
|---|---|
| `app/layout.tsx` | لغة `ar`، اتجاه `rtl`، الترويسة والتذييل |
| `app/globals.css` | تحميل Tajawal وحجم النص الأساسي وتباعد الأسطر وتعريف `glass-light` و`glass-dark` وتخصيص `story-caption` |
| `tailwind.config.ts` | مقياس أحجام الخط، ألوان `ink`, `paper`, `mist`, `line`, `muted` وربط `font-sans` بخط Tajawal |
| `components/header.tsx` | عرض الشعار والتنقل المتجاوب |
| `components/auth-form.tsx` | الشعار في نماذج المصادقة |
| `components/ui/button.tsx`, `lib/utils.ts`, `components.json` | زر UI المشترك وإعداد shadcn/ui |
| `public/qare-logo.svg`, `app/icon.svg` | الشعار الداكن للواجهة، وأيقونة تبويب برمز أبيض على خلفية سوداء |
| `public/hero-book-stack.png` | صورة كومة الكتب المقدمة من المستخدم في الهيرو |
| `public/story-hands-book.png` | صورة اليدين والكتاب المقدمة من المستخدم لقسم القصة |
| `public/editorial-library.webp` | صورة تحريرية محلية لخلفية نماذج الحساب |
| `components/landing/*` | أقسام الافتتاحية والقصة ومسارات القراءة والدعوة للانضمام |

هذه ميزة مشتركة تؤثر في الصفحات كلها ولا تستدعي REST API. مزيد من التفاصيل في [الملف الشامل](../../../docs/features/visual-identity.md).

## غير مكتمل

الثيم مركزي جزئيًا؛ بعض الدرجات الرمادية والمسافات مكتوبة مباشرة في الصفحات. لا يوجد وضع داكن أو مكتبة مكونات كاملة.
