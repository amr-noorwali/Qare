# الهوية البصرية في الواجهة

## الحالة الحالية

الواجهة عربية `rtl` ومتجاوبة. الخط الافتراضي Tajawal بأوزان 400 و500 و700 و800 من حزمة `@fontsource/tajawal`. تظهر نسخة SVG من الشعار في الترويسة ونموذج الدخول/التسجيل، ونسخة منه كأيقونة للمتصفح.

اسم المنصة الظاهر للمستخدم هو «قارئ» في الترويسة والتذييل ونموذج الدخول والعناوين. الثيم الحالي أبيض وأسود مع درجات رمادية ولوحات زجاجية شفافة في أقسام الموقع الأخرى. الهيرو يعرض صورة كومة الكتب التي قدمها المستخدم (`hero-book-stack.png`) على خلفية سوداء، مع تخطيط نص يمين/صورة يسار على الشاشات الواسعة. صورة المكتبة التحريرية بقيت خلفية لنماذج الحساب، وصورة تقليب الكتاب في قسم قصة قارئ.

## الملفات والارتباطات

| الملف | الدور |
|---|---|
| `app/layout.tsx` | لغة `ar`، اتجاه `rtl`، الترويسة والتذييل |
| `app/globals.css` | تحميل Tajawal وتعريف `glass-light` و`glass-dark` لأقسام الموقع الأخرى |
| `tailwind.config.ts` | ألوان `ink`, `paper`, `mist`, `line`, `muted` وربط `font-sans` بخط Tajawal؛ الأسماء القديمة أصبحت رمادية |
| `components/header.tsx` | عرض الشعار والتنقل المتجاوب |
| `components/auth-form.tsx` | الشعار في نماذج المصادقة |
| `components/ui/button.tsx`, `lib/utils.ts`, `components.json` | زر UI المشترك وإعداد shadcn/ui |
| `public/qare-logo.svg`, `app/icon.svg` | أصول الشعار |
| `public/hero-book-stack.png` | صورة كومة الكتب المقدمة من المستخدم في الهيرو |
| `public/editorial-library.webp`, `public/editorial-reading.webp` | صور تحريرية محلية لنماذج الحساب وقسم القصة |
| `components/landing/*` | أقسام الافتتاحية والقصة ومسارات القراءة والدعوة للانضمام |

هذه ميزة مشتركة تؤثر في الصفحات كلها ولا تستدعي REST API. مزيد من التفاصيل في [الملف الشامل](../../../docs/features/visual-identity.md).

## غير مكتمل

الثيم مركزي جزئيًا؛ بعض الدرجات الرمادية والمسافات مكتوبة مباشرة في الصفحات. لا يوجد وضع داكن أو مكتبة مكونات كاملة.
