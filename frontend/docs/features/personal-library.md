# المكتبة الشخصية في الواجهة

## الحالة الحالية

تظهر `/library` للمستخدم المسجل بتبويبات «أريد قراءته»، «أقرأه حاليًا»، «قرأته» وعدد الكتب بكل تبويب. يمكن تغيير تصنيف كتاب أو إزالته من قائمة الاختيار في صفحة تفاصيله.

التبويبات والبطاقات الآن أبيض وأسود، مع لوحات زجاجية لحالات التحميل والدخول والفراغ. لم يتغير سلوك التصنيف.

## الملفات والارتباطات

| الملف | الدور |
|---|---|
| `app/library/page.tsx` | تبويبات المكتبة، جلب الكتب، حالات التحميل والخطأ والدخول |
| `app/books/[id]/page.tsx` | قائمة اختيار التصنيف وتحديثه أو إزالته |
| `components/book-card.tsx` | عرض الكتب داخل التبويبات |
| `lib/api.ts` | نوع `LibraryBook` ودوال `library.list/save/remove` |

تبدأ صفحة المكتبة بحالة تحميل متطابقة على الخادم والمتصفح، ثم تقرأ الرمز داخل `useEffect`. هذا هو إصلاح خطأ Hydration السابق.

## الاتصال بالباك إند

`GET /api/library` و`PUT /api/library/{id}` و`DELETE /api/library/{id}`؛ كلها تحتاج Bearer token. قيم `status` هي `want` و`reading` و`read`. شرح جدول SQLite في [الملف الشامل](../../../docs/features/personal-library.md).

## غير مكتمل

لا يوجد تقدم صفحات أو تواريخ قراءة أو قوائم مخصصة. إذا انتهت الجلسة قد تظهر رسالة API بدل تحويل تلقائي إلى الدخول.
