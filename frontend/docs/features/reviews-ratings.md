# المراجعات والتقييمات في الواجهة

## الحالة الحالية

تُعرض مراجعات القراء للجميع داخل صفحة الكتاب. يستطيع المستخدم المسجل اختيار 1–5 نجوم، كتابة مراجعة، حفظها أو تعديلها أو حذفها. بعد العملية تعيد الصفحة تحميل الكتاب ومراجعاته لتحديث المتوسط والعدد.

أصبحت النجوم والبطاقات ونموذج الإدخال متسقة مع الثيم الأبيض والأسود. تظهر بطاقات المراجعات بحركة CSS خفيفة، وتستجيب أزرار النجوم والحفظ والحذف عند التفاعل، مع احترام تقليل الحركة. تستخدم النصوص والتسميات [مقياس الخط المركزي](visual-identity.md)، ونص المراجعة `leading-relaxed`؛ التفاعل لم يتغير.

## الملفات والارتباطات

| الملف | الدور |
|---|---|
| `app/books/[id]/page.tsx` | عناصر النجوم والنص، تحديد مراجعة المستخدم، حالات الحفظ والحذف |
| `lib/api.ts` | نوع `Review` ودالتا `books.review` و`books.deleteReview` و`books.get` |
| `components/ui/button.tsx` | زر الحفظ وزر الحذف |

لا توجد صفحة مراجعات أو مكون `ReviewForm` منفصل حاليًا؛ هذه الواجهة جزء من [صفحة التفاصيل](book-details.md).

## الاتصال بالباك إند

`PUT /api/books/{id}/review` مع `{rating,body}` و`DELETE /api/books/{id}/review`، وكلاهما محمي. قراءة المراجعات ضمن `GET /api/books/{id}`. قواعد التحقق والملكية وقيد المراجعة الواحدة في [الملف الشامل](../../../docs/features/reviews-ratings.md).

## غير مكتمل

لا يوجد ترقيم صفحات للمراجعات أو إعجابات أو ردود. نموذج المراجعة ما زال جزءًا من ملف صفحة التفاصيل الكبير.
