# تفاصيل الكتاب في الواجهة

## الحالة الحالية

يعرض المسار `/books/[id]` الغلاف والعنوان والمؤلف والنوع والنبذة والمتوسط والمراجعات. عند وجود جلسة، يعرض النموذج والمكتبة الشخصية أيضًا.

## الملفات والارتباطات

| الملف | الدور |
|---|---|
| `app/books/[id]/page.tsx` | تحميل التفاصيل، حالات التحميل والخطأ، عرض النصوص، وحالة المستخدم |
| `lib/api.ts` | `books.get(id)` ونوعا `Book` و`Review`؛ يستخدم أيضًا `auth.me` و`library.list` |
| `components/book-card.tsx` | رابط الدخول إلى صفحة الكتاب من القائمة والمكتبة |
| `components/ui/button.tsx` | أزرار العمليات داخل الصفحة |

الصفحة تجمع حاليًا عرض التفاصيل و[المراجعات](reviews-ratings.md) و[تصنيف المكتبة](personal-library.md) في ملف واحد. لم تُفصل هذه الأقسام إلى مكونات مستقلة بعد.

## الاتصال بالباك إند

`GET /api/books/{id}` يعيد `{book,reviews}`. عند وجود جلسة، تطلب الصفحة `GET /api/auth/me` و`GET /api/library`. التفاصيل الكاملة في [الملف الشامل](../../../docs/features/book-details.md).

## غير مكتمل

لا يوجد تحرير بيانات كتاب أو رفع غلاف. مصدر صور الأغلفة خارجي.
