# تصفح الكتب والبحث في الواجهة

## الحالة الحالية

تعرض الصفحة الرئيسية بطاقات الكتب وبحثًا بالعنوان أو المؤلف. تبدأ بطلب جميع الكتب، ثم ترسل البحث بعد توقف الكتابة 250 مللي ثانية. تعرض حالات التحميل والخطأ وعدم وجود نتائج.

تضم الصفحة افتتاحية بصورة كومة الكتب المقدمة من المستخدم، قصة قارئ، شرح حالات القراءة، ودعوة لإنشاء حساب. زرا الهيرو يقودان إلى قائمة الكتب وحقل البحث (`#book-search`)؛ لا تنشئ هذه الأقسام وظائف باك إند جديدة.

## الملفات والارتباطات

| الملف | الدور |
|---|---|
| `app/page.tsx` | الشاشة، حقل البحث بعلامة `book-search`، حالة الاستعلام والنتائج |
| `components/book-card.tsx` | بطاقة الغلاف والعنوان والمؤلف والنوع والمتوسط، ورابط التفاصيل |
| `lib/api.ts` | نوع `Book` ودالة `books.list(q)` |
| `components/landing/hero.tsx` | الافتتاحية وروابط استكشاف الكتب والانتقال لحقل البحث والتسجيل |
| `components/landing/story-section.tsx` | القصة وقيم التجربة |
| `components/landing/reading-paths.tsx` | شرح تصنيفات المكتبة |
| `components/landing/membership-cta.tsx` | دعوة لإنشاء حساب عادي، دون عضوية مدفوعة |

## الاتصال بالباك إند

`GET /api/books?q=...`. النتيجة تأتي من Go، ولا تتصل الواجهة بقاعدة البيانات. البطاقة تنتقل إلى [تفاصيل الكتاب](book-details.md). تفاصيل استعلام Go والبيانات الأولية في [الملف الشامل](../../../docs/features/catalog-search.md).

## غير مكتمل

لا توجد فلاتر أو فرز أو ترقيم صفحات، ولا شاشة لإدارة الكتب. رابط الغلاف خارجي.
