# تصفح الكتب والبحث في الواجهة

## الحالة الحالية

تعرض الصفحة الرئيسية بطاقات الكتب بأغلفتها الملونة الأصلية وبحثًا بالعنوان أو المؤلف. تبدأ بطلب جميع الكتب، ثم ترسل البحث بعد توقف الكتابة 250 مللي ثانية. تعرض حالات التحميل والخطأ وعدم وجود نتائج. أحجام الهيرو والأقسام والبطاقات وحقل البحث تأتي من [مقياس الخط المركزي](visual-identity.md).

تضم الصفحة افتتاحية بصورة كومة الكتب الشفافة المقدمة من المستخدم بحجم أصغر وفوق خلفية بيضاء، وتظهر نصوصها وصورتها بحركة CSS قصيرة، وقصة قارئ بصورة اليدين والكتاب المقدمة من المستخدم، وشرح حالات القراءة ودعوة لإنشاء حساب. حركات أقسام الصفحة وبطاقات الكتب CSS فقط، وتبقى الكتب مرئية عند عدم دعم حركة التمرير. زرا الهيرو يقودان إلى قائمة الكتب وحقل البحث (`#book-search`)؛ لا تنشئ هذه الأقسام وظائف باك إند جديدة.

## الملفات والارتباطات

| الملف | الدور |
|---|---|
| `app/page.tsx` | الشاشة، حقل البحث بعلامة `book-search`، حالة الاستعلام والنتائج |
| `components/book-card.tsx` | بطاقة الغلاف والعنوان والمؤلف والنوع والمتوسط، ورابط التفاصيل |
| `lib/api.ts` | نوع `Book` ودالة `books.list(q)` |
| `components/landing/hero.tsx` | الافتتاحية وروابط استكشاف الكتب والانتقال لحقل البحث والتسجيل |
| `components/landing/story-section.tsx` | القصة وقيم التجربة وصورة `public/story-hands-book.png` |
| `components/landing/reading-paths.tsx` | شرح تصنيفات المكتبة |
| `components/landing/membership-cta.tsx` | دعوة لإنشاء حساب عادي، دون عضوية مدفوعة |

## الاتصال بالباك إند

`GET /api/books?q=...`. النتيجة تأتي من Go، ولا تتصل الواجهة بقاعدة البيانات. البطاقة تنتقل إلى [تفاصيل الكتاب](book-details.md). تفاصيل استعلام Go والبيانات الأولية في [الملف الشامل](../../../docs/features/catalog-search.md).

## غير مكتمل

لا توجد فلاتر أو فرز أو ترقيم صفحات، ولا شاشة لإدارة الكتب. رابط الغلاف خارجي.

## ملاحظة تشخيصية

إذا ظهرت الصفحة وبقيت الكتب بلا نتائج، تحقق أولًا من `GET /api/books` ومن تحميل ملفات `/_next/static/` في المتصفح. في 2026-10-08 كانت خدمة Go تعيد ستة كتب، لكن بعض ملفات JavaScript في خادم Next.js كانت ترجع 404 بعد تشغيل البناء أثناء بقاء خادم التطوير؛ أصلح إعادة تشغيل `npm run dev` العرض. يوضح [README](../../README.md) ترتيب أوامر التشغيل.

إذا ظهر تحذير Hydration وفي الفرق الخاص بحقل البحث خاصية `fdprocessedid`، افحص إضافات المتصفح. الحقل في `app/page.tsx` لا يحدد هذه الخاصية، وHTML المحلي المستلم من Next.js لا يحتويها؛ يُحتمل أن إضافة أضافتها قبل تحميل React. جرّب نافذة خاصة دون إضافات، ثم عطّل الإضافة المسببة للموقع. لم تُضف معالجة تخفي التحذير في الكود.
