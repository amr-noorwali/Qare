# قارئ

منصة مراجعات كتب عربية بسيطة: حسابات، بحث، تفاصيل، مراجعات، ومكتبة شخصية.

شغّل [الباك إند](backend/README.md) أولًا ثم [الفرونت إند](frontend/README.md). الخادم الافتراضي على `localhost:8080` والواجهة على `localhost:3000`. كل البيانات والمصادقة في Go/SQLite؛ الواجهة تتواصل عبر REST فقط.
